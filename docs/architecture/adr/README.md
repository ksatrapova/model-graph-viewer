# Architecture Decision Records

One file per decision: `NNNN-short-title.md`, copied from [0000-template.md](0000-template.md).

- **When:** a choice that's expensive to reverse, that others will build on, or that someone will later ask "why did we do it this way?" about.
- **Status:** `Proposed` → `Accepted` (or `Rejected`). A later decision that replaces one marks the old one `Superseded by ADR-NNNN`. **Never edit an accepted decision silently.** Write a new one.
- Code that implements an ADR may reference it (`ADR-0003`) in a comment or commit.
